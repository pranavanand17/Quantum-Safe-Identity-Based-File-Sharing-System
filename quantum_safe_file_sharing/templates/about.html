PROJECT NOTES

Designed to make the cryptographic flow tangible.

Quantum-Safe Identity-Based File Sharing System is an educational cybersecurity demonstration by Pranav Anand (23MIC0006).

It simulates secure file sharing in which a recipient is selected by identity (student ID / email). That identity is resolved to an ML-KEM public key. The file is encrypted with AES-256-GCM, and the file key is protected with ML-KEM-768 encapsulation.

The design is identity-based access and key management combined with post-quantum cryptography. It is not a claim that ML-KEM is an identity-based encryption scheme.

  • Local Flask application — files never leave this machine
  • Demo authentication by selecting a student identity
  • Private keys stored as filesystem seeds under data/keys/
  • Encrypted packages stored under data/encrypted/
